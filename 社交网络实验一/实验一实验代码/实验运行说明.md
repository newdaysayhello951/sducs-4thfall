# IMDb 影评情感分类实验

## 实现内容

`sentiment_nb.py` 使用 Python 标准库手写多项式朴素贝叶斯，没有调用现成分类器，也不需要安装 Keras 或 sklearn。

- 数据：`aclImdb/train/{neg,pos}` 用于训练，`aclImdb/test/{neg,pos}` 用于最终评估。
- 预处理：解析 HTML 实体、去除 HTML 标签、转小写，提取英文单词并保留单词内部的撇号。
- 特征：unigram 词频；词表只根据训练集建立，预测时忽略未登录词。
- 参数：拉普拉斯平滑系数 alpha 默认为 1；不根据测试集调参。
- 标签：`neg` 为负面，`pos` 为正面。
- 评价：Accuracy；同时保存混淆矩阵和逐条预测以便分析错误。

## 算法原理

设类别为 c，训练集中该类评论数为 N_c，总评论数为 N，训练词表大小为 V。

先验概率：`P(c) = N_c / N`。

设 `count(w,c)` 为单词 w 在类别 c 的全部训练评论中的出现次数，则：

`P(w|c) = (count(w,c) + alpha) / (sum_v count(v,c) + alpha * V)`。

对一条评论 x，分别计算两类得分：

`score(c,x) = log P(c) + sum_w count(w,x) * log P(w|c)`。

选择得分最高的类别。这里的得分是用于比较的对数分数，并非归一化后的情感概率。

README 提供了 TF-IDF 示例，但没有强制要求使用 TF-IDF。本实现使用与多项式模型直接对应的词频特征。额外的 NRC 情感词典未用于本次基线实验。

## 运行方式

在项目根目录运行完整训练及测试：

```powershell
python sentiment_nb.py train
```

Windows 下读取大量独立小文件可能较慢，可顺序读取压缩包中的相同评论：

```powershell
python sentiment_nb.py train --archive aclImdb_v1.tar.gz
```

该方式仍严格使用 `train/pos`、`train/neg` 训练，以及 `test/pos`、`test/neg` 测试，只改变文件读取方式。原始数据仍可正常解压供查看。

预测自定义评论：

```powershell
python sentiment_nb.py predict --text "This movie was wonderful and I loved it."
```

可选参数示例：

```powershell
python sentiment_nb.py train --data aclImdb --output results --alpha 1.0
```

再次训练会覆盖指定输出目录中的同名结果文件。需要对比实验时请设置不同的 `--output`。若要选择超参数，应从训练集中划分验证集，避免根据最终测试集选择参数。

## 输出文件

- `results/model.json`：类别先验和条件对数概率，可加载用于预测。
- `results/metrics.json`：实际训练规模、词表大小、测试准确率、混淆矩阵及耗时。
- `results/predictions.csv`：每条测试评论的相对路径、真实标签、预测标签和是否正确。

训练程序会保存并重新加载模型，再进行测试，从而检查保存的模型确实可复用。混淆矩阵的第一层键是真实类别，第二层键是预测类别。

## 已做的实现检查

通过人工可计算的小数据集核对条件概率及平滑公式，检查正负预测、未登录词处理和 HTML 文本预处理。完整数据集结果见 `results/metrics.json`。

## 局限

词袋特征忽略词序，对否定表达、反讽和上下文依赖的处理有限。可在独立验证集上探索 bigram、词表过滤或 TF-IDF；这些属于后续扩展，本次先完成可复现的基础实验。
