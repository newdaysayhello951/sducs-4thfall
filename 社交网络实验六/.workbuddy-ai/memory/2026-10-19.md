## 2014 论文复现工程（repro2014/，已交付）
- 用户要求：只按论文重写代码、不许抄作者仓库、换技术栈。已全部照做（Python 3.12 + sklearn 1.5 + SciPy）。
- **核心障碍**：RepLab 2013 只发 tweet id，无正文 → 13 个特征里 8 个不可算，实际只跑 5 个（author/urls/time×3）。
- 关键实测结果：
  - Table 2 `time` 行：**0.5537 vs 论文 0.56**（强证据链路正确）
  - `all`：0.5578（5 特征）vs 论文 0.63（13 特征）
  - 话题检测：AUC 0.215 / MAR 0.556 / maxF1 0.334 vs 论文 0.41 / 0.61 / 0.47
- 三层校验：①指标实现（解析解 + 朴素独立实现，误差 0）②15 个特征单测 ③合成语料端到端（text 通路 maxF1=0.947）。
- **两个踩过的坑（重要）**：
  1. 论文式(4) 的 Lin 相似度在均匀权重下等价于 **Dice**（2|A∩B|/(|A|+|B|)），不是 Jaccard。
  2. 单链接 HAC 的簇结构由 MST 边权决定；模型弱时相似度挤在窄带，按「相似度百分位」切阈值会让曲线退化成 3 个点、AUC=0。改成在**合并高度**上扫描才正常。
  3. 官方 Perl 脚本对「系统未输出的文档」在 Reliability 记满分（$R++），不是 0，必须照做。
- 运行命令：`python -m src.run_pipeline --pairs 80000 --folds 10 --cuts 25`（约 40s）。
- 补全方法：拿到正文后加 `--text-file xxx.jsonl` 即可启用 7 个文本特征。

## 复现实验报告（Word 交付）
- 产物：`论文复现实验报告_Spina2014_话题检测.docx`（421KB，9 章 + 摘要 + 参考文献 + 附录，8855 字，10 表，3 图）。
- 走 workbuddy-docx 全链路：S1 academic-paper-expert → S2 html-template → S3 html-to-doc；pipeline 目录 `output/344dd695-.../`。
- 论文原图 Figure 1 从 PDF 第 8 页用 PyMuPDF `get_pixmap(clip=Rect(168,44,452,337), dpi=400)` 裁出。
- **踩到的三个坑（html-to-doc）**：
  1. `<img src="相对路径">` **不会**被转换；必须用**绝对路径**（`C:/.../x.png`），否则 docx 里没有 word/media。
  2. 三线表边框写在 CSS 的 `tr` 上无效（tcBorders 全 none）；必须把 `border-top/bottom` 写到 **th/td 的 inline style** 才会转成 tcBorders。
  3. 转换器会在文末生成一个空的第 4 节（sectPr 无 type，默认 nextPage）→ 多一页空白页；把该 sectPr 的 type 改成 `continuous` 即可。
