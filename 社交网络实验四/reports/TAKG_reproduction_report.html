摘要

本实验依据论文《Topic-Aware Neural Keyphrase Generation for Social Media Language》从零实现主题感知神经关键短语生成模型（TAKG），未复制或导入作者仓库代码，只保留论文公开的 Weibo 与 StackExchange 数据。本次正式实验选择 Weibo 数据集，完成数据校验、神经主题模型预训练、生成器预训练、联合训练、束搜索解码以及 F1@K、MAP@5、present/absent 分类评估。复现模型在 Weibo 测试集上取得 F1@1=32.78%、F1@3=23.46%、MAP@5=39.31%。与论文报告的 34.99%、24.42% 和 41.29% 相比，分别低 2.21、0.96 和 1.98 个百分点，但三项指标均超过论文中的 Seq2Seq-Copy 强基线。本实验说明，独立实现已正确重建序列生成、复制机制和主题感知联合学习的主要流程，但尚未完全复现论文中完整模型的增益。

关键词：关键短语生成；神经主题模型；序列到序列；复制机制；Weibo；论文复现

核心结论：本次复现属于“方法与趋势复现成功、数值接近但未完全一致”。最佳模型出现在联合训练第 3 轮，之后验证损失连续恶化，程序在第 6 轮按 patience=3 自动早停。最终 F1@1 达到论文结果的 93.7%，F1@3 达到 96.1%，MAP@5 达到 95.2%。

1　实验背景与目标

社交媒体文本短、口语化且噪声较多，用户标注的关键短语经常不直接出现在原文中。传统关键词抽取方法只能从原文选择词语，因此无法处理 absent keyphrase。论文采用生成式 seq2seq 框架，并引入语料级潜在主题，以缓解短文本中的数据稀疏问题。主题信息同时进入解码状态、注意力和生成/复制开关，使模型既能复制原文词语，也能生成原文中没有出现的关键词。

本实验的目标包括：第一，严格使用论文提供的数据，在不参考作者 GitHub 代码的条件下独立实现模型；第二，验证从数据处理到评估的完整流水线；第三，在 Weibo 测试集上与论文表 3 的结果进行同口径比较；第四，结合训练曲线和实现选择分析数值差异。

2　论文方法与模型原理

2.1　总体结构

图 1　根据论文重新实现的 TAKG 数据流

模型包含两个主体模块：神经主题模型（Neural Topic Model, NTM）读取无词序的词袋向量，学习帖子所属的主题混合；关键短语生成器读取保留词序的 token 序列，使用双向 GRU 编码帖子，再使用主题感知 GRU 解码关键短语。两个模块在联合训练阶段由同一个总损失连接。

2.2　神经主题模型

词袋编码器用两层 ReLU 感知机处理归一化 BoW，分别预测高斯潜变量的均值 μ 与对数方差 log σ²。训练时使用重参数化采样，推理时使用均值以保证同一检查点的预测稳定。潜变量经过 softmax 映射得到 50 维主题混合 θ，并由主题—词分布重构原始词袋。

z = μ + ε ⊙ exp(0.5 log σ²)，　θ = softmax(fθ(z))
LNTM = −Σw xw log p(w|θ) + KL(q(z|x) || N(0,I))

代码中的 NeuralTopicModel.forward() 实现编码、重参数化、主题混合和词袋重构，topic_model_loss() 实现重构负对数似然与 KL 散度之和。

2.3　主题感知生成与复制机制

序列编码器为两层双向 GRU，每个方向隐藏维度为 150，拼接后得到 300 维编码表示。解码器为单层 300 维 GRU。主题向量 θ 在三个位置发挥作用：

  1. 与当前输入词向量拼接后更新解码状态，对应论文公式 5；
  2. 加入源词注意力能量函数，对应论文公式 6—7；
  3. 加入生成/复制概率 λ 的计算，对应论文公式 10。
p(yj) = λj · pgen + (1−λj) · pcopy

复制分布由注意力权重构成。对于词表外但在当前帖子中出现的词，代码为每条帖子建立局部扩展词表，再通过 scatter_add 将注意力概率累加到相应扩展索引。这样既能生成固定词表中的词，也能复制当前原文中的 OOV 词，同时避免不同帖子之间的 OOV 索引泄漏。

2.4　联合训练目标

关键短语生成损失采用 teacher forcing 下的 token 级负对数似然，联合目标与论文一致：

L = LNTM + γLKG，　γ = 1.0

训练顺序为 NTM 预训练 100 轮、冻结 NTM 后预训练生成器 1 轮、随后联合训练。联合阶段中生成损失可以通过主题向量反向传播到主题网络。

3.2　数据处理

公开数据中的正文与标签按行对应，多个关键短语以分隔符存储。训练时把一条正文的多个关键短语展开为多个“正文—单个短语”样本，因此 37,036 条训练帖子形成 39,188 个训练对。正文最大长度设为 100，目标最大长度设为 10。词序序列供 GRU 使用，词袋计数供 NTM 使用。

词表由训练集构建，生成词表大小为 50,000，BoW 词表大小为 10,000。每条帖子单独维护 OOV 列表；若目标 OOV 在源帖子中出现，则其监督标签指向扩展词表索引，否则使用 UNK。

3.3　训练、保存与恢复

train.py 为 topic、generator 和 joint 三个阶段分别建立 Adam 优化器。每轮结束后将模型参数、三个优化器状态、训练计划、配置与 Python/NumPy/PyTorch 随机状态保存至 last.pt。文件采用临时文件替换的原子写入方式，因此实验中断后可从最近完整轮次继续。联合训练依据验证集 generation NLL 保存 best.pt。

3.4　推理与评价

推理采用 beam size 50、最大生成长度 6，候选按累计对数概率排序，不额外采用长度惩罚。重复短语去重后保留前 50 个候选。评价时计算宏平均 P@K、R@K、F1@K 与 MAP@5，并依据关键短语是否在正文中连续出现，拆分为 present 和 absent 两组。

7　结果不一致的原因分析

7.1　随机种子数量不同

论文表 3 报告 5 个随机初始化种子的均值与标准差，本次受 CPU 时间限制只运行 seed=9527。神经网络的初始权重、样本打乱顺序和 VAE 采样都会引入随机性，因此单次结果可能偏离论文均值。要进行严格复现，应至少运行 5 个种子，并报告均值、标准差和显著性检验。

7.2　论文没有给出全部工程细节

论文明确给出了主题数、GRU 层数和维度、词向量维度、学习率、梯度裁剪、预训练轮次与 γ，但没有完整说明 NTM 每层的精确结构、参数初始化、归一化方式、方差参数化、dropout 位置和优化器状态切换方式。本实现采用两层 ReLU 的 BoW 编码器、多项式词袋重构、log-variance 截断以及推理时使用潜变量均值。这些选择符合论文描述，但不保证与作者实现逐项相同。

7.3　联合优化与早停策略差异

论文描述为依次更新各模块及其组合，但没有给出每种更新的精确频率与 patience。本实现先预训练两个模块，再使用独立 joint Adam 优化器一次性更新全部参数，并设置 patience=3。训练曲线显示第 3 轮后训练 NLL继续下降而验证 NLL上升，早停选择是合理的；但如果论文采用不同的交替更新、学习率衰减或更长 patience，可能获得更好的联合主题收益。

7.4　束搜索排序和候选后处理差异

论文只说明采用 beam search，没有完整描述长度归一化、重复 token 限制、UNK 过滤、短语去重、候选截断与无效短语处理。本实现按累计对数概率排序且不加入长度惩罚，这可能偏好较短的候选。F1@1 与 MAP@5 对候选顺序敏感，因此解码细节足以造成 1—2 个百分点的差距。

7.5　评价实现边界

本实现对 Weibo 使用分词 token 的小写精确匹配，present 必须是正文中的连续 token 片段；英文数据才使用 Porter stemming。论文只概括说明采用宏平均 F1 和词干化匹配，没有给出中文符号清理、重复标签和空预测等边界情况。宏平均 P/R 后再计算 F1、逐样本先计算 F1 再平均等实现顺序也可能造成细微差异。

7.6　数据展开与目标组织方式

本实现把一条帖子对应的多个关键短语展开为多个一对一训练样本。论文给出了数据统计和 seq2seq 目标，但没有完整说明多标签帖子在训练批次中的组织方式。若作者把多个关键短语拼接为一个序列，或采用不同的采样/加权方法，目标分布和每个 epoch 的有效样本权重都会发生变化。

7.7　CPU、软件版本与数值路径

本次使用 CPU 和 PyTorch 2.5.0；论文发表于 2019 年，使用的 PyTorch、底层 BLAS、随机数实现和数值稳定策略均可能不同。硬件不会系统性决定模型优劣，但浮点累积顺序会使优化轨迹逐渐分叉。该因素通常小于架构和解码差异，但在单种子比较中不能忽略。

综合判断：最主要的原因是“单种子比较 + 论文未公开的训练/解码细节 + 联合训练更新方式”。从指标位置看，本次结果已经超过 Seq2Seq-Copy，却接近论文 separate-train 消融模型，说明差距主要集中在主题模块与生成器的联合增益，而不是基础 seq2seq 或复制机制失效。

8　结论

本实验仅使用论文公开数据，完成了 TAKG 的独立代码复现。实现覆盖 VAE 神经主题模型、两层双向 GRU 编码器、主题感知解码状态、主题感知注意力、主题感知复制开关、扩展词表、三阶段训练、断点续训、beam search 和完整评价。训练过程稳定，6 项正确性测试全部通过，最佳检查点能够在测试集上生成 present 与 absent 关键短语。

测试结果与论文总体趋势一致：主题感知模型超过复制式 seq2seq 基线，对 present 关键词表现尤其突出，并具备生成 absent 关键词的能力。主指标距离论文完整模型 0.96—2.21 个百分点，属于接近复现。若继续提高复现精度，建议依次进行：5 个随机种子重复实验；复核宏平均计算与中文预处理；尝试论文描述的模块交替更新；对 beam search 长度归一化和候选过滤进行消融；比较不同 patience 与学习率衰减设置。
