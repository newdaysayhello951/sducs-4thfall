- Epinions Alchemy：https://alchemy.cs.washington.edu/data/epinions/ 页面有效；epinions.tgz 响应200，Content-Length为330018128字节，已成功读取前30MB并看到内部原始网页归档 epinions/epinions-nouserpages.tar.gz。未完整下载和验证；这不是已整理成评分/信任表的数据。该版本与665K版不能混用。
- Trustlet HTTPS入口：证书验证失败；HTTP入口502。不能将这一访问失败断言为数据永久消失。
- Flixster旧SFU地址：本次请求超时。作者新主页 https://sites.google.com/view/mohsenjamali/home 有 Flixster Data Set 页面 https://sites.google.com/view/mohsenjamali/flixter-data-set ，但其嵌入的Google Drive文件夹 0B2B7102TE1nbdjBTaGFCUkNtU3M 返回404，未取得数据。TrustSVD使用其子集，即使取得完整原始数据仍需核对子集选择。
- Douban：https://www.cse.cuhk.edu.hk/irwin.king.new/pub/data/douban 返回404，未核验到论文所用原始数据。
- Ciao：ASU旧来源被重定向到Cloudflare Access登录页；MSU迁移来源HTTPS握手失败，HTTP502，未取得文件。CiaoDVD是不同数据集，不应替代TrustSVD所用Ciao。
- Meetup活动推荐：本次未找到并成功下载可对应原论文三城市数据的原始文件；未确认可用，不等于证明没有公开过。
