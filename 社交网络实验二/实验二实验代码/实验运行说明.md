# 新闻摘要实验运行说明

## 运行

在项目目录打开终端，安装依赖后运行：

```powershell
python -m pip install -r requirements.txt
python -m unittest -v test_experiment
python run_experiment.py
```

默认处理全部有效新闻，同时运行 Lead-3、手写 TextRank（词重叠）和 TF-IDF 余弦图排序对照。无需 GPU、模型下载或 gensim。原始 `gensim_summary.py` 保留为教学示例，不参与新实验。

快速验证和参数扫描：

```powershell
python run_experiment.py --limit 100 --output results_small
python run_experiment.py --limit 100 --study --output results_study
python run_experiment.py --sentences 4 --damping 0.9 --output results_k4
```

`--limit 0` 使用全部数据；正数使用种子 42 随机抽样，可用 `--seed` 更改。输入文件先按名称排序。不同实验应指定不同输出目录，否则同名结果文件会覆盖。

## 文件职责

- `load_data.py`：读取正文和 highlights，缺少标记时返回空 highlights。
- `textrank.py`：分句、分词、相似度、转移矩阵、手写 PageRank、选句。
- `metrics.py`：ROUGE-1/2/L 和语料级 BLEU-4。
- `run_experiment.py`：数据筛选、对照实验、参数扫描、结果导出。
- `test_experiment.py`：解析、已知稳态分布、孤立节点、摘要顺序、指标边界测试。

## 算法说明

每个句子为一个节点，不添加自环。排名用小写词元并过滤 `textrank.py` 中固定停用词表。默认相似度为共同不同词数除以 `log(1+句1词数)+log(1+句2词数)`；加 1 避免短句分母为零。这是明确采用的词重叠变体。

TF-IDF 对照使用单篇文章的句子计算 IDF：`log((1+句子数)/(1+含词句子数))+1`，TF 使用词频，边权为余弦相似度；属于 LexRank 风格的相似度选择。

行归一化后，孤立节点转移到所有节点的概率均为 `1/N`。列向量排名更新为 `p_new=(1-d)/N+d*M.T*p`，初始值 `1/N`，默认 `d=0.85`。L1 差小于 `1e-6` 或达到 200 次停止；未收敛数量会被记录。选出得分最高的 k 句后按原文顺序拼接，同分优先前面的句子。空文本返回空摘要。

分句采用规则实现，保护常见称谓和首字母缩写，但对复杂引号、特殊缩写和不规则换行仍可能有误差；这应作为实验局限说明。构图需要句子两两比较，存储复杂度 O(N²)。

## 评测口径

同一篇文章的所有 highlights 拼为一个参考摘要。生成摘要和参考摘要均小写并提取英文/数字词元，不做停用词过滤、词干化。ROUGE-1/2 分别统计一元/二元词组的截断重叠；ROUGE-L 计算整个摘要的最长公共子序列。CSV 同时提供逐篇宏平均 precision、recall 和 F1；不是 ROUGE-Lsum。

BLEU 使用整个语料累加后的 1–4 阶匹配计数，几何平均结合长度惩罚，无平滑；任一阶无匹配时为零。所有分数范围 0–1。未实现 ROUGE-BE。本项目自实现指标，没有调用 sumeval，也不保证和 README 示例中的 sumeval 默认设置逐值一致。

## 输出和报告分析

- `config.json`：参数、环境版本、评测口径、无效文件 ID。
- `dataset_stats.json`：样本数、平均正文和参考摘要词数。
- `metrics.csv`：总体分数、词数、算法耗时、迭代次数和未收敛数。
- `predictions.jsonl`：每篇每种方法的摘要、参考、句子下标、排名（TextRank）、指标和耗时，可按 ID 找回原始 `.story`。
- `report.md`：可直接阅读的结果表和前三篇固定案例。

报告应解释 TextRank 与 Lead 基线的差异，并结合原文检查关键信息覆盖、冗余和指代问题。相同句数不等于相同词数，要结合平均摘要长度解读；不要预设 TextRank 一定优于 Lead。

参数扫描比较句数 1–5 和阻尼 0.70、0.85、0.95（默认配置）。属于同批样本的探索性分析。如果依据结果挑选参数，需另行划分开发集和测试集，不能把同批数据的最优结果称为独立测试结果。算法耗时不包含指标计算和文件读取，取决于机器环境。

## 生成式算法（了解部分）

Encoder 将新闻编码为内部表示，Decoder 从开始标记逐步生成摘要直至结束标记。它能够重组语言，但需要训练且可能产生事实偏差；抽取式方法直接选取原文句子。README 仅要求了解生成式算法，本项目不训练 Encoder–Decoder。
